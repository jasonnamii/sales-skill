## 한국 5대 고유 패턴

### 1. Pre-RFP 관계영업 (엔터프라이즈·B2G 핵심)
- "RFP 떴을 때 영업 시작 = 이미 진 게임"
- 승부는 RFP 이전 3-6개월 관계 구축·판짜기에서 결정
- 활동: 임원 미팅·세미나·POC 제안·내부 챔피언 발굴

### 2. 부트캠프(밀착) 영업
- 삼성SDS 팔란티어式 모델: 고객사 현장 상주 + 문제 공동해결
- 챗GPT 엔터프라이즈 리셀러 사례 (2024)
- 복합 솔루션 + 신뢰 구축에 효과적

### 3. 공공조달 (나라장터)
- 조달청 공고 기반 입찰
- RFI → RFP → 평가 → 낙찰 프로세스
- 평가기준: 기술(60-80%) + 가격(20-40%)
- 한국 고유: 인증·실적·장애인기업·여성기업 가산점

### 4. 채널 (총판·리셀러·파트너)
- 한국 B2B = 채널 비중 높음. 직판보다 총판 효율
- 사례: 삼성SDS 챗GPT엔터프라이즈 리셀러, 메가존 GCP 총판
- 채널 파트너 인센티브·MDF(마케팅 개발 자금)·교육·인증 체계 필수

### 5. 이커머스 (쿠팡·네이버 양강)
- 양강 구도: 쿠팡(로켓·마켓플레이스) · 네이버 스마트스토어(40만+ 스토어, 2020)
- 수수료: 쿠팡·G마켓·11번가 10% 전후 / 홈쇼핑·백화점 20%
- MD 영업: 셀러 모집·관리, 상품가↔노출 교환

## 도메인별 한국 오버레이 강도

| 도메인 | 강도 | 적용 핵심 |
|--------|------|----------|
| D1 SaaS | **약** | 대부분 글로벌 수렴. 단, 한국 SaaS 벤더 도구·언어·결제 한국화 |
| D2 엔터프라이즈 | **강** | Pre-RFP 관계영업 + 부트캠프영업 + 채널 |
| D3 B2C | 중 | 메신저(카카오)·네이버 검색 광고 비중 높음 |
| D4 D2C | 중 | 네이버페이·토스·결제 한국화 + Meta·네이버 광고 혼합 |
| D5 리테일 | **강** | 쿠팡·네이버·올리브영·CU/GS25/세븐일레븐 입점 영업 |
| D6 B2G | **강** | 나라장터 + 공공 평가기준 + 인증·실적 |

## 한국 의사결정 구조 특수성

| 패턴 | 영향 |
|------|------|
| 위계적 의사결정 | Champion만으론 부족. Economic Buyer(임원)·Coach(실장급) 동시 공략 |
| 합의 중시 | "사장님 한 마디"보단 부서장 합의 → 다수 DM 동시 관리 |

| 사례·레퍼런스 중시 | 동종업계 사례 ≥ 글로벌 사례. "삼성·LG도 쓴다"가 강력 |
| 가격 협상 후행 | 기술·관계 확정 후 마지막에 가격. 초반 가격 노출 위험 |

## 한국 RFP 대응 5단계

```
① Pre-RFP (3-6개월) — 임원 미팅·POC·챔피언 발굴
② RFI 응답 — 기술 사양·실적 제출
③ RFP 분석 — 평가기준 역설계·차별화 포인트 도출
④ 제안서 작성 — 기술+사례+가격 + 한국식 깔끔한 PPT
⑤ 발표·질의응답 — 임원 직접 발표 (대표 or CTO)
```

---

## 한국 채널 영업 5단계

```
① 파트너 발굴 — 업종·지역·역량 매칭
② 자격심사 — 재무·기술·영업력
③ 계약 — 마진율·MDF·교육·인증·KPI
④ 인에이블먼트 — 제품교육·세일즈교육·기술인증
⑤ 운영 — 분기 비즈리뷰·딜등록·MDF 정산
```
