# D1 B2B SaaS 도메인 오버레이

## 핵심
PLG·PLS·SLG 혼합. 사이클 30-90일. ACV $5K-$100K. NRR·ARR 핵심.

## 퍼널 매핑 (L2 메타퍼널 적용)
| 메타 | SaaS 단계 |
|------|----------|
| 획득 | Visitor → Lead (콘텐츠·SEO·광고·아웃바운드) |
| 자격 | MQL → SQL → SAL (BANT/SPIN) |
| 전환 | Trial → Paid (PLG) or Demo → Contract (SLG) |
| 유지 | NRR·갱신 (CSM 주도) |
| 확장 | Upsell·Seat·신모듈 |

## 추천 방법론 (복잡도별)
- Light(<$10K): BANT + SNAP, PLG 자기서비스
- Mid($10K-$100K): SPIN + Solution Selling, PLS 시그널 기반 영업 인수인계
- Heavy($100K+): MEDDIC + Challenger, SLG 풀세일즈

## KPI (도메인 오버레이)
- ARR · NRR(110%+) · GRR(90%+) · Logo Retention · ACV · CAC Payback(<18개월) · Magic Number(>0.7) · Rule of 40

## 스택 추천
- 소규모: HubSpot + Apollo
- 중형: Salesforce/HubSpot + Outreach + Gong + Clay
- 대규모: Salesforce + Outreach + Gong + ZoomInfo + Clay + 6sense

## 한국 오버레이 (강도: 약)
- 글로벌 수렴. 단, 한국 SaaS는 채널톡·리캐치·콜라보 등 로컬 도구 활용
- 결제·세금계산서·언어 한국화 필수

## Gotchas
| 함정 | 대응 |
|------|------|
| PLG 도입 후 영업 손놓음 | PLS = 시그널 기반 영업 인수인계 필수 |
| NRR만 보고 GRR 무시 | Expansion으로 Churn 가리는 함정. GRR 별도 추적 |
| Trial 전환률 2-5% 정상인데 낮다고 판단 | 톱티어 10%+ 외 평균 2-5% 정상 범위 |
