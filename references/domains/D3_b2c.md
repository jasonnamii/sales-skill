# D3 B2C 도메인 오버레이

## 핵심
짧은 사이클·충동구매·1인 의사결정. AIDA·AARRR 퍼널. 마케팅과 세일즈 경계 흐림.

## 퍼널 매핑
| 메타 | B2C 단계 |
|------|---------|
| 획득 | Awareness (광고·SNS·검색) |
| 자격 | Interest (클릭·비교·검색) |
| 전환 | Action (구매) |
| 유지 | Repeat (재구매) |
| 확장 | Loyalty (멤버십·추천) |

## 추천 프레임
- AIDA (Awareness·Interest·Desire·Action) — 마케팅 퍼널
- AARRR (Acquisition·Activation·Retention·Referral·Revenue) — 서비스·앱
- RFM (Recency·Frequency·Monetary) — 고객 세그먼테이션

## KPI
- Conversion Rate · AOV · CAC · Repeat Purchase Rate · NPS · 이탈률

## 한국 오버레이 (강도: 중)
- **카카오톡 채널·알림톡** 대화형 세일즈 보편
- **네이버 검색광고** 비중 높음 (구글보다 우선)
- **라이브커머스** (쿠팡라이브·네이버쇼핑라이브)
- **리뷰·별점** 영향 큼

## Gotchas
| 함정 | 대응 |
|------|------|
| MEDDIC 등 B2B 방법론 적용 | AIDA·AARRR로 전환 |
| 복잡도 라우터 적용 시도 | B2C는 라우터 대신 퍼널 중심 |
| NRR 적용 | 구독 없으면 Repeat Rate로 대체 |
