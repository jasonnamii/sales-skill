# D2 엔터프라이즈 도메인 오버레이

## 핵심
사이클 90-180일+. ACV $100K+. 5+ DM. ABM·Deal Desk·Champion 중심.

## 퍼널 매핑
| 메타 | 엔터 단계 |
|------|----------|
| 획득 | Account ID → ABM 타겟 → Engagement |
| 자격 | Champion 발굴 → MEDDIC/MEDDPICC 풀 |
| 전환 | POC/Pilot → Procurement → Contract |
| 유지 | QBR · 갱신 · 사용 확대 |
| 확장 | Cross-sell · 신모듈 · 신부서 |

## 추천 방법론
- 기본: **MEDDIC + Challenger**
- 경쟁심화: MEDDPICC + Challenger
- 한국 엔터: MEDDIC + Pre-RFP + 부트캠프영업 (한국Heavy)

## ABM 핵심 5요소
1. ICP 기반 타겟 계정 리스트 (50-200개)
2. Champion·EB·Coach 매핑 (계정당 5-10명)
3. 채널 오케스트레이션 (LinkedIn·이메일·DM·이벤트·웹세미나)
4. 컨텐츠 퍼스널라이제이션 (인더스트리·페르소나)
5. RevOps 트래킹 (계정 진척도·인게이지먼트 스코어)

## Deal Desk
- $100K+ 딜은 Deal Desk 검토 필수
- 가격·계약·법무·승인 경로 표준화
- AE 단독 결정 ✗

## KPI (도메인 오버레이)
- Deal Size · Win Rate(20-30%) · Sales Cycle · Pipeline Coverage(4-6x) · Champion Score · Quota Attainment

## 한국 오버레이 (강도: 강)
- **Pre-RFP 관계영업** 3-6개월 필수 (RFP 떠서 시작 = 진 게임)
- **부트캠프 영업** (현장 상주, 삼성SDS 모델)
- **사례·레퍼런스** 우선 (글로벌 사례보다 국내 동종업계)
- **위계적 의사결정** — Champion만으론 부족, EB(임원) 직접 공략
- **가격 후행** — 초반 가격 노출 위험

## Gotchas
| 함정 | 대응 |
|------|------|
| Champion만 믿고 EB 미공략 | 한국은 Champion+EB+Coach 3중 동시 |
| RFP 응답에만 집중 | Pre-RFP에서 평가기준 역설계 가능 |
| 글로벌 ABM 표준 그대로 적용 | 한국은 LinkedIn보다 인맥·세미나·전시회 |
