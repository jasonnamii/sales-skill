# D6 B2G (공공조달) 도메인 오버레이

## 핵심
한국 고유. 나라장터 기반 입찰. RFP·평가기준·인증·실적 중심.

## 퍼널 매핑
| 메타 | B2G 단계 |
|------|---------|
| 획득 | RFI 인지 · 공공 담당자 관계구축 |
| 자격 | RFP 응찰 자격심사 · 입찰 참여 |
| 전환 | 평가 · 낙찰 · 계약 |
| 유지 | 사후 운영 · 연장계약 · 사업 확대 |
| 확장 | 인접 사업 · 신규 RFP · 타 기관 |

## 한국 공공조달 프로세스
```
정보공개(나라장터) → RFI 제출(선택) → RFP 공고 → 응찰(자격심사·제안서·가격)
→ 기술평가(60-80%) + 가격평가(20-40%) → 낙찰 → 계약 → 사업 수행
```

## 평가기준 요소 (일반적 가중)
| 요소 | 가중 | 핵심 |
|------|------|------|
| 기술능력 | 40-60% | 인력·경험·방법론·사례 |
| 가격 | 20-40% | 예가 대비·저가심의 |
| 수행능력 | 10-20% | 재무·조직·보안 |
| 가산점 | 5-15% | 중소기업·여성기업·장애인기업·지역기업·품질인증 |

## Pre-RFP 관계영업 (핵심)
- RFP 공고 전 6개월-1년 담당 공무원·연구관 관계구축
- 정책 방향·예산·평가 방향 사전 파악
- RFI 응답으로 방향성 제시 (유리한 방향 유도)
- RFP 공고 후 시작 = **이미 진 게임**

## 인증·실적
- 필수 인증: CMMI, ISO27001, ISMS, 소프트웨어품질인증(GS)
- 한국 고유: 직접생산증명, 중소기업확인서, 벤처기업·이노비즈·메인비즈
- 가산점: 여성기업·장애인기업·사회적기업

## 추천 방법론
- **MEDDIC + Pre-RFP 한국오버레이**
- M(Metrics): 정량 평가지표 파악
- E(EB): 부서장·국장급 · 예산 결재권자
- DD(Decision Criteria): 평가표 역설계
- D(Decision Process): RFP 일정·조달청 절차
- I(Pain): 공공 미션·정책 과제 이해
- C(Champion): 담당 주무관·연구관

## KPI
- 입찰 참여율 · 낙찰률 · 평균 계약액 · 갱신률 · 평가점수

## Gotchas
| 함정 | 대응 |
|------|------|
| RFP 공고 후 영업 시작 | 3-6개월 앞 Pre-RFP 필수 |
| 가격만 낮추기 | 저가심의·이행가능성 평가 있음. 기술 차별화가 핵심 |
| 평가기준 무시하고 자사 강점만 어필 | 평가표 역설계 → 가중치 높은 항목 집중 |
| 가산점 인증 미준비 | 5-15% 가산점은 박빙 낙찰의 결정타 |
