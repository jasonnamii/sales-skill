# L4 STACK — 세일즈 테크 스택 4계층

**벤더 중립 원칙:** 특정 도구 예시로만 명시. 2026 MCP·AI Agent 재편 급속.

---

## 4계층 구조 (2025-2026)

| 계층 | 역할 | 대표 예시 |
|------|------|----------|
| **CRM 코어** | 계정·연락처·딜 시스템 오브 레코드 | Salesforce · HubSpot · Pipedrive · Zoho |
| **데이터·인텔리전스** | ICP 매칭·인리치먼트·시그널 | ZoomInfo · Clay · Landbase · Apollo DB |
| **실행 (Engagement)** | 시퀀스·아웃바운드·인바운드 자동화 | Outreach · Salesloft · Apollo · HubSpot Sequences |
| **대화 인텔리전스** | 콜 녹음·코칭·딜 포캐스트 | Gong · Chorus · Chorus.ai |

## 2026 트렌드 (시점 감쇠 주의 — 빠른 변화)

| 트렌드 | 내용 | 시사 |
|--------|------|------|
| **MCP 채택** | Gong·Outreach 2026.2 MCP 표준 채택 | 커스텀 통합 ✗ → AI 도구 간 컨텍스트 공유 자동 |
| **컨솔리데이션** | 10-15개 → 4-5개 "인텔리전스 공유 도구" | 스택 과다 = 비효율·데이터 분산 |
| **AI Sales Agents** | Clay·11x·Regie 등 AI BDR 등장 | 아웃바운드 자동화 레벨업, 인간 AE는 복합 딜에 집중 |
| **Gong Mission Andromeda (2026.2.25)** | 코칭+챗봇+MCP 통합 | 대화IQ 카테고리 지형 변화 |

## 선택 기준 체크리스트

| # | 질문 | 결정 |
|---|------|------|
| 1 | CRM 있는가? | 없으면 CRM 먼저 |
| 2 | 아웃바운드 비중 높은가? | Yes → 실행 계층 필수 |
| 3 | 복합 딜 포캐스팅 필요한가? | Yes → 대화IQ 필수 |
| 4 | ICP 명확한가? | No → 데이터IQ로 ICP 정의 |
| 5 | 팀 규모 10명↑? | Yes → Salesforce 고려 / No → HubSpot |

## 한국 현실 스택 오버레이

글로벌 스택 그대로 적용 주의:
- **중소·중견 한국 기업:** Salesforce 도입률 낮음 → 엑셀·HubSpot·네이버웍스·카카오채널+스프레드시트 현실
- **한국 SaaS 벤더:**
  - CRM: 채널톡 (채팅+CRM) · 리틀팩토리 · 메이크샵
  - 세일즈 인에이블먼트: 리캐치 (리콜팩트)
  - 대화IQ: 콜라보(Callabo) · AI녹음·요약
  - 이메일 마케팅: 스티비
- **공공조달:** 나라장터 입찰 관리 별도 도구 (민간 SaaS 연동 어려움)
