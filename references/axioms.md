# Axioms — sales-skill 6대 설계 원칙

리서치(A·B·C·D·E축)에서 도출한 본질 규칙. 모든 산출물·로직이 따라야 함.

| # | 원칙 | 근거 | 위배 시 |
|---|------|------|--------|
| 1 | **블렌딩 원칙** | A축: 2025 표준 = 단일 방법론 ✗, 블렌딩 만연 | 단일 방법론 강요 → 실무 저항 |
| 2 | **벤더 중립** | D축: 2026 MCP·AI Agent 재편 급속 | 벤더 하드코딩 → 6개월 내 노후화 |
| 3 | **오버레이 차등** | E축: SaaS=글로벌 수렴 / 엔터·공공·리테일=한국 강 | 일률 강도 → 부적절 추천 |
| 4 | **5층 독립+Cascade** | I1: 단일 호출과 풀진단 모두 필요 | 강제 cascade → 비효율, 분리만 → 시너지 손실 |
| 5 | **정성+정량 병기** | C축: 글로벌 KPI 수렴+한국 정성 고유 | 숫자만 보면 한국 맥락 누락 |
| 6 | **한국 디폴트 True** | 사용자 절대 다수 한국 기업 | 해외 디폴트 → 매번 한국 명시 부담 |

## 검증
- 산출물에 단일 방법론만 등장? → ① 위배
- "Salesforce 도입하세요" 직접 권장? → ② 위배
- D2 엔터프라이즈에 한국 오버레이 약 적용? → ③ 위배
- L1만 요청했는데 L1~L5 풀 답변? → ④ 위배
- 진단서에 숫자만 있고 정성 분석 없음? → ⑤ 위배
- 한국 기업에 글로벌 답변? → ⑥ 위배
