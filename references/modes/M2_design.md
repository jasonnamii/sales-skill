# M2 설계 모드

목표·제품·도메인 입력 → 세일즈 플레이북 설계. 방법론·퍼널·KPI·도구·조직 액션.

## 입력
- 목표 (ARR·신규 로고·갱신·확장)
- 제품 (ICP·ACV·차별화)
- 도메인 (D1~D6)
- 현재 조직 (AE·BDR·CSM 수, 경험)
- 제약 (예산·기간)

## 절차
1. **복잡도 라우팅** → 방법론 매칭
2. **L1~L5 각 층 설계:**
   - L1: 방법론 블렌딩 + QA 프롬프트
   - L2: 퍼널 스테이지 정의 + Exit Criteria
   - L3: 목표 KPI + 주간/월간/분기 cadence
   - L4: 스택 추천 + 도입 로드맵
   - L5: 한국 오버레이 (강/중/약 자동)
3. **도메인 오버레이** 적용
4. **실행 플레이북** 산출

## 산출물 포맷 (.md)

```markdown
# {제품}_세일즈 플레이북_v1

## 1. ICP·컨텍스트
## 2. 딜 복잡도 판정
## 3. 방법론 블렌딩
   - 퀄: {BANT/MEDDIC/MEDDPICC}
   - 설득: {SPIN/Challenger/Sandler/SNAP}
## 4. 5스테이지 퍼널 + Exit Criteria
## 5. KPI 대시보드 (주/월/분기)
## 6. 스택 추천 + 12개월 도입 로드맵
## 7. 한국 오버레이 (적용 강도)
## 8. 조직 설계 (AE:SDR:CSM 비율, Quota)
## 9. Quick Win 30/60/90일
## 10. 리스크·의존성
```

## Gotchas
- 플레이북이 너무 길면 실무 미준수. 핵심 1-page + 상세 어펜딕스 구조 추천
- 방법론 블렌딩 시 중복 개념(MEDDIC의 Pain과 SPIN의 Problem) 매핑표 포함
- 한국 기업엔 한국 오버레이 강 자동 적용
