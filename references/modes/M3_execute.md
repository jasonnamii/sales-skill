# M3 실행 모드

특정 상황(콜·이메일·RFP·미팅)에서 즉시 사용할 스크립트·템플릿·체크리스트.

## 입력
- 상황 (콜드 콜·팔로업 이메일·디스커버리 미팅·데모·제안·RFP·클로징)
- 도메인·복잡도
- 고객 정보 (산업·회사 규모·페르소나)
- 목적 (미팅 잡기·니즈 발굴·이의제기 대응·클로즈)

## 산출물 유형

### 1. 콜드 아웃리치 (이메일·LinkedIn·콜)
- 제목·오프닝·가치제안·CTA 3버전 (톤 변형)
- 팔로업 시퀀스 5-7단계
- 참고: copywriting-skill 호출로 문구 정제

### 2. 디스커버리 미팅
- 아젠다 15-30분 템플릿
- MEDDIC/SPIN 질문 리스트 10-15개
- 노트 템플릿 (Metrics·EB·Pain·Timeline)

### 3. 데모 시나리오
- 오프닝 5분 → Pain 확인 5분 → 제품 10-15분 → Value 5분 → Next Step 5분
- 산업·페르소나별 맞춤 포인트

### 4. 제안서·RFP 대응
- Executive Summary 1p
- 이해·솔루션·차별화·실적·팀·가격·일정 구조
- 한국 B2G: 평가표 역설계 기반 구성

### 5. 이의제기 대응 (Objection Handling)
- 가격·타이밍·권한·신뢰 4대 이의
- Feel-Felt-Found 공식
- 근거·레퍼런스·사례

### 6. 클로징·계약
- Assumptive Close · Alternative Close · Urgency Close
- Paper Process 체크리스트
- 협상 지점은 negotiation-skill 위임

## 실무 체크리스트

### 콜 전 체크
- [ ] 회사 리서치 (투자·뉴스·제품·경쟁)
- [ ] Persona 파악 (역할·책임·KPI)
- [ ] 목표 1가지 (미팅 잡기 / 니즈 확인 / 데모 약속)
- [ ] 예상 이의 3개 + 대응

### 이메일 체크
- [ ] 제목 8단어↓
- [ ] 오프닝에 개인화 1줄
- [ ] 가치제안 2-3문장
- [ ] CTA 1개 (복수 ✗)
- [ ] 서명 간결

### 미팅 후 체크
- [ ] 24시간 내 팔로업
- [ ] 요약 + Next Step + 타임라인
- [ ] CRM 업데이트 (MEDDIC 필드)

## Gotchas
- 문구 세부 디자인은 copywriting-engine으로 cascade 권장
- 협상 지점 진입 시 negotiation-skill로 이동
- 한국 이메일은 글로벌 대비 존댓말·첨부·회사소개 비중 ↑
